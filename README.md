# ControlIncidenciasIOS

Aplicación Nativa para iOS desarrollada en **SwiftUI** con diseño **Liquid Glass**.

## Compilación Gratuita en GitHub Actions
Este repositorio cuenta con un flujo de trabajo automático en `.github/workflows/ios-build.yml` que compila la aplicación en un servidor macOS de GitHub y genera el ejecutable `.ipa` descargable en la sección **Actions**.
